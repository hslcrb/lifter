## 바로 사용하기
1. [설치 ZIP 다운로드](https://github.com/hslcrb/lifter/raw/refs/heads/main/dist/lifter-3.1.0.zip) 후 압축을 풉니다.
2. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드** → `manifest.json`이 있는 폴더를 선택합니다.
4. 일반 웹사이트에서 Lifter 아이콘을 누르면 **사이트 위에 플로팅 패널**이 나타납니다. **L을 가져가~**를 누르세요.
5. **돌려놓기** 또는 새로고침으로 원상복구합니다.

v1에서 업데이트했다면 확장 관리 화면에서 새로고침한 뒤, 열려 있던 웹페이지도 새로고침하세요.

스토어에 게시된 제품은 아닙니다. 소스 ZIP을 받은 경우에는 `extension/` 폴더를 선택하세요.

## v3: 이미지도 발음도 기억도 쏙
- **이미지 속 L도 가져가**: 로컬 OCR이 확신한 L/l/ㄴ 계열을 찾아 문자 폭 × 행 높이 사각형을 실제 투명 PNG로 만듭니다. 원본 파일은 바꾸지 않고 표시만 바꾸며, 돌려놓기로 복원합니다.
- **한글 발음 장난**: 롯데→오떼, 롯데리아→오떼이아, 라면→아면, 서울→서우. 정식 발음 변환기가 아닌 의도적인 밈 규칙입니다.
- **계속 기억**: 첫 수집 때 사이트 권한을 허용하면 다음 방문과 동적 로딩에도 자동 적용합니다. 확장 전용 IndexedDB에 사이트 규칙과 가공 이미지 캐시를 보관합니다. 전체 HTML을 얼려서 재생하지 않아 사이트 동작을 유지합니다.
- **돌려놓기**는 현재 탭에서 잠시 중지. **기억 지우기**는 해당 사이트의 기억·이미지 캐시·자동 실행을 지웁니다. 일반 HTTP 캐시 삭제와 확장 데이터 삭제는 별개입니다.
- **웹폰트**: 눈누에서 확인한 여기어때 잘난체 + Pretendard Regular/Bold, 원본·라이선스 동봉. [폰트 표본](docs/TYPOGRAPHY.md)
- [릴리즈](https://github.com/hslcrb/lifter/releases/tag/v3.1.0): **설치 전체 ZIP**(OCR·폰트 포함)과 **전체 소스 ZIP**.

## 작은 장난, 꼼꼼한 동작
- **L · l · ㄴ**은 무조건 한패. 전각·수학체 L, ℓ/ℒ/Ⅼ, ㄴ/ᄂ/ᆫ/ﾤ, └/┗/╰/⌊/∟ 및 라틴 L 악센트 변형도 수집합니다. 숫자 1, 대문자 I, 한글은 위 발음 장난 규칙을 적용하고 분해형 음절은 보존합니다.
- 툴바 팝업 없이 사이트 위에 계속 떠 있습니다. 접기·닫기를 지원하고 툴바로 다시 열 수 있습니다.
- 글자 팝 → 휘어지는 비행 → 뿌숭/빠슝 말풍선 → 주머니 충격파와 축포. 비행은 최대 24개, 축포는 28개로 제한합니다.
- 패널 내부는 평소 선택·드래그가 잠겨 있습니다. **우클릭 → 복사 — 형광펜 모드**에서 드래그 선택 후 Ctrl/Cmd+C 또는 복사 버튼을 누르면 축포! 실제 복사 성공 시에만 표시합니다.
- 링크 주소, 입력값, 편집 영역, 스크립트, SVG와 캔버스는 그대로 둡니다.
- 원래 텍스트 노드와 이벤트를 유지합니다. 복원 중 사이트가 수정한 내용은 덮어쓰지 않습니다.
- 동적으로 나타난 글자는 다시 클릭해서 수집합니다. 열린 Shadow DOM도 지원합니다.
- OS의 모션 감소 설정을 존중합니다. 효과를 직접 끌 수도 있습니다.
- 웹페이지 내용은 전송하지 않습니다. [개인정보 안내](docs/PRIVACY.md)

## 범위
렌더링되는 DOM 텍스트가 대상입니다. 이미지는 별도 버튼으로 정적 PNG/JPEG/WebP/BMP를 처리합니다(8MB·400만 픽셀 이하). CSS 배경·가상 요소, GIF/SVG, 닫힌 Shadow DOM, 다른 프레임은 대상이 아닙니다. 이미지 인식은 완벽하지 않으며 75 이상 신뢰도의 문자만 지웁니다. 브라우저 내부 화면, 웹 스토어, 일부 보호된 페이지에서는 작동하지 않습니다. 기억한 사이트는 재방문 시 자동 적용됩니다. 패널은 툴바로 열 수 있습니다. 최초 화면이 잠깐 보일 수 있습니다. 기억 중에는 동적 변경도 다시 수집합니다.

## 개발 / 체험
```sh
npm ci
npm test
python3 scripts/package.py
python3 -m http.server 8765
```
`http://localhost:8765/docs/demo/`에서 설치 없이 같은 엔진으로 수집·복원을 체험합니다. 체험판도 실제 `extension/panel.js`를 그대로 사용합니다. 테스트는 jsdom에서 실행되며 실제 브라우저의 확장 권한을 대체하지 않습니다.

## 내장 놀이터 — 월요일 회피 연구소

확장 아이콘 우클릭 → 옵션을 누르거나, 새 탭/브라우저 내부 화면에서 확장 아이콘을 누르면 열립니다. 오프라인으로 동작하는 가상의 콜라주 페이지입니다. `싹 가져가`로 텍스트·한글·포스터를 수집하고, 원상복구 또는 플로팅 주머니의 기억 지우기로 되돌릴 수 있습니다. 새 댓글도 기억 상태에 따라 자동 수집합니다. 소리는 체크할 때만 재생됩니다.

직접 그린 이미지 포스터는 알려진 글자 좌표를 사용해 7곳을 즉시 투명 처리합니다. 일반 웹사이트 이미지 OCR과 구분됩니다. 놀이터 기억은 확장 페이지의 localStorage에 저장되며 일반 사이트 기억(IndexedDB)과 별개입니다.
