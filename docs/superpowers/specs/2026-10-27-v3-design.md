# Lifter v3: local image heist + lasting site memory

User delegates implementation. Scope: recognize L-shaped image text, remove symbol-width/full-line-height rectangles to real alpha; playful Korean transformations including 롯데→오떼; persist across navigation; choose/bundle Noonnu fonts; publish full installation ZIP and source ZIP in release.

Approach: packaged Tesseract.js 6.0.1 + local eng/kor models in an offscreen extension document. No OCR uploads or CDN runtime scripts. 75% symbol confidence, 8MB/4MP image limits, sequential queue. Low-confidence and unsupported images reported, never represented as recognized. Image restore preserves site edits.

Persistence: extension-origin IndexedDB stores site settings and bounded content-hashed processed PNGs. Per-site optional host grants + registered isolated content scripts reapply the engine at document_idle and after dynamic changes. HTML response caching was rejected because it freezes sessions, scripts and live content. Storage is visible and deletable through Forget; normal browser HTTP-cache clearing does not clear extension IndexedDB. Explicit Forget is authoritative. No promise of avoiding first-paint flashes.

Fonts: title/actions Jalnan, body/controls Pretendard regular+bold. Unmodified bundled binaries with original license notices, no runtime CDN dependency.

Korean is a playful spelling transform, not formal phonology: 롯데 exception→오떼; rieul onset→silent ieung; rieul final removal including compound finals. Existing standalone L/ㄴ family retained. NFD full syllables remain protected.
